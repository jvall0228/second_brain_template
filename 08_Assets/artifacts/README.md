# Generated Local Artifacts

This directory contains two deterministic, self-contained local views generated by `brain artifacts --write`:

- [link-graph.html](link-graph.html) — a bounded searchable link graph with safe relative note navigation.
- [health-dashboard.html](health-dashboard.html) — derived link, freshness, Inbox, task, and expiry counts without task text or note bodies.
- [manifest.json](manifest.json) — schema, generator, controlled snapshot time, source scope, input digest, and exact output hashes.

Preview with `brain artifacts`; verify with `brain artifacts --check`; open both fresh files with `brain artifacts --open`. In VS Code, use **Brain: Preview Artifacts** or **Brain: Open Artifacts**. In Obsidian, open this README and follow the generated-file links above through the system browser; the HTML files are ordinary local assets.

Only the dedicated writer owns the three named outputs. Do not hand-edit them. The rest of `08_Assets/` remains append-only by default.

The HTML is offline: no CDN, remote font, telemetry, fetch, or other runtime network path. Hosting is disabled and not shipped. A future hosted copy requires a separate environment-scoped configuration, explicit owner consent, and a privacy review; notifications are a separate capability.
