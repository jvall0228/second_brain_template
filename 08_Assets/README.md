# Assets

Non-markdown files — images, PDFs, attachments, and other binary assets referenced by vault notes.

## When to Put Something Here

Any file that isn't a markdown note: screenshots, diagrams, exported PDFs, audio clips, etc. Reference these from notes using standard markdown or Obsidian embed syntax (`![[filename.png]]`).
