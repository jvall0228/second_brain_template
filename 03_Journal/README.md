# Journal

Personal knowledge and experience — what you think, understand, and observe. Periodic notes (daily through yearly) are date-organized. Subdirectories capture durable understanding: ideas, insights, memories, people, and plans.

The key distinction: **Journal is subjective** (your perspective), **Resources are objective** (shareable knowledge). A physics concept is a Resource; your idea for applying it is a Journal entry.

## When to Put Something Here

Ask: **"Is this my perspective, understanding, or experience?"**

- **Yes** — It's a Journal entry. Put it here.
- **No, it's shareable reference material** — It's a Resource. See [[06_Resources/README]].
- **No, it has a specific outcome and deadline** — It's a Project. See [[04_Projects/README]].
- **No, it's an ongoing responsibility** — It's an Area. See [[05_Areas/README]].

## Structure

### Subdirectories

| Directory | Purpose |
|-----------|---------|
| `periodic/daily/` | Daily logs — `YYYY-MM-DD.md` |
| `periodic/weekly/` | Weekly reviews — `YYYY-WNN-review.md` |
| `periodic/monthly/` | Monthly reviews — `YYYY-MM-review.md` |
| `periodic/quarterly/` | Quarterly reviews — `YYYY-QN-review.md` |
| `periodic/yearly/` | Yearly reviews — `YYYY-review.md` |
| `ideas/` | Ideas, brainstorms, and speculative concepts |
| `insights/` | Personal reflections, self-knowledge, and wisdom |
| `memories/` | Narrative accounts of notable events |
| `people/` | Character studies and observations about people |
| `plans/` | Strategies and structured approaches for life areas |
