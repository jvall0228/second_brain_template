# Periodic Notes

Time-based reflections and reviews organized by cadence.

## Subdirectories

| Directory | Cadence |
|-----------|---------|
| `daily/` | Daily logs — `YYYY-MM-DD.md` |
| `weekly/` | Weekly reviews — `YYYY-W##-review.md` |
| `monthly/` | Monthly reviews — `YYYY-MM-review.md` |
| `quarterly/` | Quarterly reviews — `YYYY-Q#-review.md` |
| `yearly/` | Yearly reviews — `YYYY-review.md` |
