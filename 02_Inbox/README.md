# Inbox

This is the default landing zone for all new content — raw capture, agent-generated output, and unsorted notes. Everything placed here is considered **untriaged**. A human periodically reviews Inbox contents and moves them to the appropriate PARA directory (`04_Projects/`, `05_Areas/`, `06_Resources/`, or `07_Archives/`). Notes that don't belong anywhere may be deleted or merged.

When creating a new note here, include frontmatter with at least `title`, `tags` (including `audience/agent` if agent-generated), and `updated`. Use `workflow/draft` as the default workflow tag for Inbox items.
