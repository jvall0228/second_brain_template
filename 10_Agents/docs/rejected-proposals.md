# Rejected Proposals

The [self-improve](../skills/self-improve/SKILL.md) loop's rejection memory: every proposal the owner rejected (PR closed unmerged, or Inbox proposal rejected at triage), one row each. **Append-only** — rows are never edited or removed; this log is why the loop never re-proposes an idea the owner already declined. Re-raising a listed item requires materially new evidence, stated explicitly in the new proposal ("previously rejected on `<date>`; re-raising because …").

Consult this table **first**, before proposing anything. `—` in the "why rejected" column means the owner gave no reason — never invent one.
