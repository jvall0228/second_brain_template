# Archives

Completed, cancelled, or no longer relevant items. The Archives are the "cold storage" of the vault — content that's done serving its purpose but worth keeping for reference.

## When to Put Something Here

Ask: **"Is this completed, cancelled, or no longer actively relevant?"**

- **Yes** — Archive it here.
- **Still active with a deadline** — It's a Project. See [[04_Projects/README]].
- **Still an ongoing responsibility** — It's an Area. See [[05_Areas/README]].
- **Still useful as reference** — It's a Resource. See [[06_Resources/README]].

The key test: Would you be surprised to find this in an "active" section? If yes, archive it.

## Structure

Mirror the source structure:
- `07_Archives/projects/` — completed or cancelled projects
- `07_Archives/areas/` — areas you've stepped away from
- `07_Archives/resources/` — outdated reference material
- `07_Archives/inbox/` — Inbox items that served their purpose without migrating to PARA
- `07_Archives/outbox/` — shipped (or abandoned) Outbox packets, moved here with `status/done` — see [[02_Outbox/README]]
- `07_Archives/assets/` — large or obsolete assets moved from `08_Assets/`
